# Account types and hosted tunnels — security checklist

Acceptance criteria for the [revised #1172 plan](<Account Types and Hosted Tunnels Plan.md>). Ten controls at ten points each. **Required implementation score: 100/100.** All rows await implementation evidence. Record a shipping commit, platform, test command, exit code and redacted result for each row.

Cloudflare terminates TLS and can read or change ordinary application traffic, bearer headers and terminal upgrades. The hostname permits probing and bounded signed discovery. Only an issuer-authorized owner bearer opens a bridge session. A connector credential permits a replica to join its tunnel. It is a separate secret from both a client bearer and the Cloudflare account management token.

| # | Control | Passing evidence |
| --- | --- | --- |
| 1 | Account policy | Migrate existing users and approve new ones with free/false defaults. Exercise all type/entitlement combinations. Verify correct issuer/UUID, idempotent operator change and audit. A suspended or foreign account cannot claim. Promotion succeeds with a paired bridge offline. |
| 2 | Resource ownership and lifecycle | Record generation, random label and recoverable protected secret before provider I/O. Simulate lost create replies, missed nudges, restart, quota and re-pair. Adopt only the exact Build-owned tunnel and DNS target. With an incomplete inventory or ambiguous ownership, preserve resources. **Dangling-CNAME test:** fail DNS deletion and assert the tunnel still exists. After retry, verify DNS absent before tunnel deletion, then neither resource remains. |
| 3 | Credentials and single use | Verify scoped account and wrapping secrets, signed claim purpose/audience, current pairing, nonce, SQL replay and transactional challenge spend across workers. Reject stale-generation and cross-account claims. Search user listings, IPC, argv/env, logs, dumps and archives for fixture credential markers. Inspect owner-only on-disk credential permissions and encrypted DB material. |
| 4 | Connector binary and local ingress | Check the signed release manifest, correct platform/digest and operator override. Reject a tampered binary; verify zero downloads for free or personal bridges. Exercise the pinned binary with the exact-host rule, Unix socket in a 0700 directory and final 404. Qualify the local-credentials/verified-loopback-TLS fallback if needed. Use the real pinned binary with a loopback mock edge to push replacement ingress. Verify the supervisor kills and reaps the child, reports hosted unavailable, quarantines the generation across daemon restarts, and the replacement origin receives no connections in the test. Requests can race in the window from the child applying a push to supervisor detection and process termination. Outbound confinement is a follow-up. Verify unsupported modes fail closed, one child survives normal supervision, and shutdown/crash leaves no serving orphan. Require Linux evidence; advertise macOS only with equivalent macOS evidence, otherwise release hosted bridges on Linux only. |
| 5 | Single endpoint and authenticated client | Start with a personal origin (also test invalid settings): no hosted provision or fallback. Switch to/from hosted and verify the existing predecessor CAS and family invalidation on origin, epoch or enabled change. Check paired proof, account, active membership, bearer, Opening and scope for REST/SSE/ticket issuance. DNS knowledge, preflight, discovery or a foreign bearer gives no protected data. |
| 6 | Revocation and replacement | Unpair/revoke while REST, SSE and WSS are active. New introspection refuses immediately. Cached authority expires within 30 seconds and never beyond bearer expiry. Tickets redeem once within 15 seconds. Simulate a bridge missing the change. Delete DNS then the old tunnel and recreate with a new UUID/credential; the old connector cannot join. Verify a newer personal endpoint survives stale hosted cleanup. |
| 7 | RTC policy at issuer, relay and clients | With RTC disallowed, refuse ICE and gateway mint for entitled callers and refuse new device signaling sockets. Observe the existing socket sever at the next 60-second recheck with the issuer reachable. An issuer outage preserves the authenticated socket. Existing DataChannels may finish. Count **zero new RTC dials** on modern HTTPS-only clients, including terminal recovery. Exercise the single bootstrap exception with two devices at different readiness, verify it stays off after first ready and repeat with the exception disabled. Free direct/TURN still works. |
| 8 | Cache and compatibility | Cold-start offline, switch accounts, rotate origin, replay a stale pull and mount with an old preload. Device views use the current account's committed device record. Record terminal capability in cache before first render, including unknown/unsupported. Missing WSS cannot start terminal RTC on entitled HTTPS. An old issuer/bridge/client retains its documented free/manual path or gets upgrade guidance. |
| 9 | Public edge and native boundary | Require a wildcard certificate covering the dedicated bridge zone and forbid per-host issuance. Verify exact Host/CORS/CSP, TLS validation, redirect refusal, bounded discovery at the local connector, cache bypass and log redaction. Observe synthetic REST/SSE/WSS content at the test TLS terminator. Issuer cookies and desktop OAuth stay at the issuer; native bridge credentials stay in main. Exercise SSE idle/reconnect and WSS under load. |
| 10 | Disclosure and operational recovery | Render corrected landing, sign-in return, PWA and Settings. Show Cloudflare readability once per promotion, persist the acknowledgement, and preserve the always-available path explanation. Demonstrate personal precedence, free-account continuity, rollback and final provider inventory on dev. Record the exact installed binary and fresh mode-appropriate evidence for the new service invocation. |
