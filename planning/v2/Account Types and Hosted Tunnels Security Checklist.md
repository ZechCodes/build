# Account types and hosted tunnels — security checklist

Release gate for [#1172's plan](<Account Types and Hosted Tunnels Plan.md>) on base `4d6c962efab9a3a4c3c9598a52875efd62d5c0ad`. The protected assets include account authority, pairing identity, Cloudflare management credentials, per-bridge connector tokens, Build bearer families, terminal control, and code or prompts carried over the network.

**Trust boundary.** Hosted HTTPS terminates at Cloudflare. Cloudflare can read or modify application payloads and credentials in transit. A connector token holder can attach a replica and may receive requests including live credentials. A holder of the Cloudflare management token can also reconfigure ingress within its permissions. A person who only knows the hostname can contact the public edge, probe availability and obtain a bounded, purpose-specific signed discovery response. Build must verify current owner authority for every protected opening. The security argument for hosted mode trusts the edge and the connector control plane. On the free WebRTC path, TURN relays encrypted traffic between the two peers.

**Required score: 100/100.** Each row is worth ten points, earned only with passing evidence for the shipping revision. All ten rows are pending implementation. Record the tested commit, platform, command, exit code and redacted evidence in each owning review. Historic manual-HTTPS or WebRTC results establish regression baselines.

| 10 | Account ownership and promotion | Migrate a populated database, register a new user through an old worker, and read free/false in both cases. Exercise all four combinations. An operator update by verified UUID is idempotent and rejects wrong environment, unknown UUID and stale revision. Ordinary account, admin classification, suspended user and foreign device cannot promote, claim or manage another bridge. Audit contains the before/after policy and operator. |
| 10 | Provision only the intended resources | Commit approval concurrently with promotion, revoke, unpair and account deletion. Two workers, offline device, response loss after every Cloudflare call, 429 and quota exhaustion converge to one correctly owned tunnel/hostname or a verified cleanup tombstone. Verify no external billing mutation. Assert unowned DNS records are preserved and predecessor cleanup cannot touch a re-pair. |
| 10 | Separate credentials and resist replay | Inspect Secret references and actual process environment in a disposable deployment. Only the provisioner can manage the selected account/zone. Signed claim, ack and policy routes verify pinned issuer/device, nonce, purpose, audience, revision, expiry and single use in the database. Deny replay, foreign identity and revoke-during-fetch. Inspect list/status, browser storage, IPC, DB/outbox, cached responses, logs, argv/env, crash diagnostics and archives for synthetic secret markers. On the bridge filesystem, only the permitted per-invocation child token file may contain its sentinel. |
| 10 | Local connector confinement and recovery | Assert loopback-only bind, exact Host/SNI, restricted origin CA/key files, verified TLS, catch-all 404, private working directory and one supervised child. Invalid chain/hostname, wrong target, untrusted executable path and unsafe file permissions fail closed. Exercise restart on lost response, occupied port, child crash, parent crash and upgrade on Linux/macOS. Reap child and remove credentials on revoke/shutdown. A replacement process cannot serve with a stale local registration. |
| 10 | Independent endpoints and caller authentication | Run personal and managed endpoints for one device. Try sibling origin, device, account, epoch, conflicting CAS and stale owner across discovery, family mint, renewal and introspection. Legacy manual proofs work only in the manual slot. Header/preflight/discovery probes without a bearer get no protected content. Wrong scope, expired/revoked parent or missing Opening refuses REST/SSE and terminal tickets. Check size/time/rate limits under one connector peer and daemon-wide resource ceilings across two listeners. |
| 10 | Revocation and rotation have bounded effects | Revoke with live REST, SSE and WSS. New introspections refuse immediately and old positive evidence ends by verification-start + 30 seconds or earlier expiry. A terminal ticket redeems once and expires within 15 seconds or earlier authority expiry. A lost control channel closes the managed listener and connector within the 60-second management lease. Rotate the connector token, evict existing replicas, reject the old credential and reopen through the new generation. Test provider outage during deletion and restart of both workers and bridge. Hosted-only revocation preserves personal grants; device unpair revokes both. |
| 10 | No entitled WebRTC, including existing peers | Test legacy ICE POST, previously issued gateway/TURN tokens, an already-authenticated relay socket and separate terminal rendezvous. Drain an active peer after its signaling socket closes. An offline legacy peer prevents promotion completion without verified shutdown/removal. Use counters at ICE mint, relay session admission, browser peer construction and bridge RTC dispatch. Zero successful RTC admissions after cutover; a modern entitled client performs zero RTC dials. Free accounts continue to use direct and TURN paths. |
| 10 | Cache isolation, version skew and personal choice | Cold mount, offline, stale pull after revoke, two tabs, re-pair, desktop account switch and reconnect all render the correct cached policy. Exercise old bridge/new client, new bridge/old client, old issuer and new SPA/old preload. Manual address wins on both clients. Expiry, incompatible WSS, permission failure or earlier saved WebRTC selection never sends entitled work through RTC. A failed manual connection never silently moves private traffic to the hosted edge. |
| 10 | Edge, browser and desktop data boundaries | Observe synthetic REST, SSE and terminal sentinels at the fixture TLS terminator. Verify the public and loopback TLS certificates independently. Exercise exact account CSP for HTTPS/WSS, CORS, cross-origin redirect refusal, cookie omission, and main-process handle teardown. Disable edge caching and header/body/ticket capture. Run browser/native terminal, long idle SSE, reconnect, file-size limits and slow readers without duplicate writes. Verify the private half of a push key and sealed secret values stay within their own documented boundaries. |
| 10 | Operator, disclosure and rollback | Inspect rendered landing, sign-in/return pages, PWA metadata, Settings and public privacy docs against the copy inventory. Require explicit Cloudflare readability and conditional WebRTC E2EE. Record owner-confirmed target UUID, environment, package/zone/certificate and budget, contractual decision for commercial use, rollback rehearsal and final inventory. Prove dev verification uses the exact new service invocation. Prod requires Zech's separate authorization. |

## Amend existing evidence at implementation

- [Account HTTP Security Checklist](<bridge-http-910/Account HTTP Security Checklist.md>) — add two-slot uniqueness, origin-specific CAS and revocation, issuer-assigned hosted origin, delegation to the edge, token delivery distinct from client grants, bounded document CSP and concurrent migration tests. Preserve signed one-use discovery, introspection and expiry deadlines.
- [Device Pairing Security Checklist](<Device Pairing Security Checklist.md>) and [Invite Security Checklist](<Invite Security Checklist.md>) — add approved-owner allocation, re-pair with a new generation, independent profile defaults, active membership and admin privilege boundaries. Prove the public pairing/status routes expose no connector secret.
- [Terminal WebSocket Security Checklist](<Terminal WebSocket Security Checklist.md>) — repeat the authenticated ticket/Origin/Opening tests through TLS termination. Include loss, expiry, rotation, mixed versions and missing native capability with the entitled RTC fallback disabled. Closing a socket ends remote control; already-started shell processes follow existing terminal semantics.
- [Desktop Security Checklist](<Desktop Security Checklist.md>) — add hosted-source selection, issuer-only OAuth, device-bound native bridge credentials, certificate/redirect refusal and account change during recovery. Hosted and manual native handles cannot substitute for one another.
- [Bridge Update Security Checklist](<Bridge Update Security Checklist.md>) and [Installed CLI Probe Security Checklist](<Installed CLI Probe Security Checklist.md>) — verify executable provenance, service PATH, owner-only token-file support, crash/restart cleanup and mode-specific deploy evidence. Remote package updates remain an operator responsibility.
- [Push Content Security Checklist](<Push Content Security Checklist.md>) — preserve sealed notification payload and private-key custody tests. Qualify the `push.registerKey` transport assumption: the hosted TLS terminator sees the subscription public key and is trusted during its registration. Test ordinary application traffic and sealed notification payloads separately.
- [Secret Wire Security Checklist](<Secret Wire Security Checklist.md>) and [Device Secret Vault Security Checklist](<Device Secret Vault Security Checklist.md>) — verify sealed upload bytes over the managed endpoint against the paired device key. Scope any confidentiality claim to those values. Surrounding paths, metadata and terminal output can be visible at the edge.

The dev pilot supplies provider-path evidence after Zech sets up the network and credentials. A local TLS proxy and fake provider can qualify authentication, policy transitions, retry safety and client behavior before that pilot. Record both environments explicitly in the implementation reviews.
