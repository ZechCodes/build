# Harness icon sources

These files contain compact marks extracted from official project assets. Their
geometry is preserved while document metadata, fixed dimensions, masks, styles,
and unused wordmark paths have been removed.

## Codex

- Official product page and source asset: <https://developers.openai.com/codex>
- Official extension listing: <https://marketplace.visualstudio.com/items?itemName=openai.chatgpt>
- OpenAI brand guidelines: <https://openai.com/brand/>

`codex.svg` is the monochrome OpenAI blossom used by the official Codex product
page and current Codex editor extension. OpenAI does not publish a separate
open-source license for this mark. It remains an OpenAI trademark and is included
here only to identify the Codex integration.

## Claude Code

- Official page: <https://code.claude.com/docs/en/overview>
- Source SVG (light): <https://mintcdn.com/claude-code/c5r9_6tjPMzFdDDT/logo/light.svg>
- Source SVG (dark): <https://mintcdn.com/claude-code/c5r9_6tjPMzFdDDT/logo/dark.svg>
- Project license: <https://github.com/anthropics/claude-code/blob/main/LICENSE.md>

`claude.svg` is the orange Claude spark extracted from the official Claude Code
lockup. Anthropic does not publish a separate open-source license for this logo.
The Claude Code repository states © Anthropic PBC, all rights reserved, with use
subject to Anthropic's Commercial Terms of Service. The mark is included here
only to identify the Claude Code integration.
