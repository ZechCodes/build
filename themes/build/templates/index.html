Capabilities

Everything you need to coordinate agents at scale

Agent chat

Direct communication with any agent on any device. Send instructions, review code, and iterate in real time with full message history.

Project planning

Full issue tracker with priorities, assignees, checklists, and activity feeds. Agents update their own progress as they work.

File browser

Browse agent workspaces with a full file tree, inline diffs, and version control integration. See exactly what changed and why.

Complications

Always-visible status cards for git, CI/CD, tests, tokens, and model info. Per-agent context at a glance without switching views.

Local first

Your data stays on your devices. No cloud dependency for core functionality. Works offline, syncs when connected. You own everything.

E2E encrypted

Every message, file, and command is end-to-end encrypted. Not even we can read your data. Zero-knowledge architecture throughout.

Observability
