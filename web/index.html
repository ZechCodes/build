It ran an encrypted round-trip to a bridge over the relay socket. The relay is a rendezvous now, not a data plane: it carries session setup and WebRTC signaling, and a bridge refuses any other frame offered to it (relay_is_not_a_data_plane). A browser is live only over the two DataChannels it negotiates.

The browser client that does that is spa/, served by the app at /app/. The Node half of the same path is web/client.mjs + web/peer.mjs, exercised by npm run e2e and npm run qa against deploy/compose.real.yml.
